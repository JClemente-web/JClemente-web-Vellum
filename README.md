# VELLUM OS

Operational Intelligence + Evidence OS. This repository is the greenfield foundation.

Phase 0 boots the workspace, strict TypeScript, local Postgres with PostGIS, and the tenant-isolation proof. It does not ship a product surface.

## Boot

1. Node 24 (see `.nvmrc`). Engines require `>=24.21.0 <25`.
2. `npm ci`
3. Follow `docs/runbooks/phase-0-local.md` after that runbook exists.

Canonical host and legal name are deferred. Public routes stay `noindex`.
